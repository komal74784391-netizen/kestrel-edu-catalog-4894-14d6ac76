# Kestrel Solstice C55 Classroom Display

The Solstice C55 is a 55-inch 4K interactive display designed for primary
and secondary classrooms. The panel uses an anti-glare bonded glass
surface, a fanless thermal enclosure and a replaceable pen tray, and it
ships with the KestrelClassroom management suite pre-installed.

## Overview

The C55 is the entry model in the Solstice classroom range and the most
common unit in K-12 refresh projects. It supports simultaneous pen and
finger input, has an integrated 20W speaker bar, and mounts on the
standard Kestrel wall bracket (sold separately). Deployments typically
pair it with the Solstice mobile cart for shared-resource rooms.

## Included accessories

- One active stylus and one passive stylus
- HDMI 2.0 cable (2 m)
- Region-specific power cable
- Quick-start guide and warranty card

## Compatibility

The C55 works with the KestrelClassroom 4.x software suite and the
Solstice mobile cart (part KS-CART-M). Third-party VESA 400x400 mounts
are supported but not warranted. Firmware updates are delivered in-region
by the reseller desk.
